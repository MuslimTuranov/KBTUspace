# KBTUspace Frontend

React + TypeScript + Vite frontend for KBTUspace.

## Setup

```powershell
npm.cmd install
```

Create `.env` if you need a non-default API URL:

```env
VITE_API_URL=http://localhost:8080/api/v1
```

## Development

```powershell
npm.cmd run dev
```

Open `http://localhost:5173`.

## Production Build

```powershell
npm.cmd run build
```

## Lint

```powershell
npm.cmd run lint
```

## Main Screens

- Login/Register
- Feed
- Events
- Event details and registration
- Profile
- Admin panel for moderation, reports, and users
